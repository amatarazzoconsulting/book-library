## Introduction

The Multi-Language Just-In-Time (JIT) Compiler System represents a significant advancement in the field of dynamic code generation and execution, providing developers with a powerful

framework that can parse, analyze, and execute code written in multiple programming languages including C, C++, Python, Go, BASIC, COBOL, and JavaScript. This system is built upon a sophisticated architecture that combines lexical analysis, syntax parsing, abstract syntax tree generation, and machine code emission into a unified pipeline that seamlessly handles the syntactic nuances of different programming languages while producing efficient native code for multiple CPU architectures. The compiler system addresses a critical gap in existing JIT solutions, which typically support only a single source language or require extensive modification to

accommodate different syntaxes, by providing a language-agnostic frontend that automatically detects the source language and applies the appropriate parsing rules. At the heart of this system lies a comprehensive tokenization engine that recognizes language-specific keywords, operators, and constructs, transforming raw source code into a stream of tokens that can be processed by a unified parser backend. The parser then constructs an abstract syntax tree that captures the semantic structure of the program, which is subsequently fed into a multi-target code generator that produces executable machine code for X86-64, ARM64, or RISC-V architectures. This design philosophy ensures that developers can write performance-critical code in their preferred language syntax while benefiting from the speed of native code execution, all within a single cohesive framework that eliminates the need for separate interpreters or virtual machines.

The system's ability to handle object-oriented programming constructs, including classes,

inheritance, polymorphism, and virtual method dispatch via vtable generation, makes it particularly suitable for large-scale application development where code organization and reusability are paramount. The implementation of vtables follows the standard object-oriented memory layout, where each class instance contains a pointer to a table of virtual function addresses, enabling efficient dynamic dispatch without the overhead of runtime type information lookups. This vtable mechanism is automatically generated by the compiler when it encounters virtual method

```text
declarations, ensuring that polymorphic behavior works correctly across inheritance hierarchies while maintaining binary compatibility with C++ calling conventions. The system also provides comprehensive support for primitive data types including integers of various sizes (8, 16, 32, and 64-bit both signed and unsigned), floating-point numbers (32 and 64-bit), boolean values, strings, and composite types such as vectors, lists, maps, and sets. Each data type is represented internally through a unified Box class that provides type-safe conversion methods and arithmetic operations, allowing the compiler to perform type checking and optimization without losing type information during the compilation pipeline.
```

## Features

The Multi-Language JIT Compiler System incorporates an extensive array of features that collectively provide a complete solution for dynamic code generation and execution across multiple programming paradigms and CPU architectures. At the core of the system lies a sophisticated language detection mechanism that analyzes source code for characteristic patterns including shebang lines, keyword frequencies, and syntactic markers to automatically identify the

```text
programming language being used, eliminating the need for developers to manually specify language preferences. This detection algorithm employs a scoring system that weighs various indicators, such as the presence of specific keywords like "class" for C++ or "def" for Python, the use of curly braces versus indentation for block delimitation, and the occurrence of language-specific operators like "->" for C++ or "::" for scope resolution. Once the language is identified, the system activates the corresponding lexical analyzer that recognizes language-specific tokens including keywords, operators, and punctuation, while still maintaining a unified token
```

representation that the parser can process uniformly regardless of the source language.

```text
The system provides complete support for bitwise operations, which are essential for systems programming, embedded development, graphics processing, and cryptographic applications where direct manipulation of individual bits is required. The implemented bitwise operators include bitwise AND, OR, XOR, and NOT, as well as left and right shift operations, all of which follow the standard precedence rules found in C and C++ where shift operators have higher precedence than bitwise AND but lower than arithmetic operators. The class system within the JIT compiler provides full support for object-oriented programming concepts including inheritance, polymorphism, encapsulation, and abstraction, enabling
```

The system implements comprehensive error handling mechanisms that capture and report compilation and runtime errors with detailed diagnostic information including source file locations, line numbers, and stack traces. When a syntax error is encountered during parsing, the system reports the offending token along with the expected token types and provides suggestions for correction based on common language patterns. Runtime errors such as division by zero, null pointer dereferencing, out-of-bounds array access, and type mismatches are caught by the execution engine and converted into typed exceptions that can be handled by user-provided

problematic code sections that require optimization or refactoring. Additionally, the system provides configurable security levels that can restrict access to certain APIs or operations based on the security context, enabling the JIT to be safely used in sandboxed environments such as web browsers or plugin systems.

## Quick Start

Getting started with the Multi-Language JIT Compiler System requires only a few lines of code and basic understanding of the core classes, making it accessible to developers of varying skill levels. The first step is to include the main header file and create an instance of the JITCompiler class, which serves as the primary interface for code generation and execution across all supported CPU architectures and optimization levels. The compiler constructor accepts two optional parameters: the target CPU type which defaults to X86-64 for maximum compatibility, and the optimization level which defaults to O2 for balanced performance and compilation speed. Once the compiler is instantiated, developers create a MultiLanguageJIT wrapper object that will handle the parsing and execution of source code from various languages, providing a clean abstraction layer that hides the complexity of lexical analysis and syntax parsing. The wrapper object automatically detects the programming language used in the source code string and configures the appropriate tokenizer and parser without requiring any manual intervention from the developer.

After creating the MultiLanguageJIT object, the next step is to register any custom API functions that the JIT code will call, using the registerAPI method which associates a function name with a C++ callback that can be invoked from within the JIT-compiled code. These callbacks accept a vector of Box objects as arguments and return a Box value, providing a type-safe interface for passing data between the JIT runtime and the host application. The system comes pre-registered with several useful APIs including print, println, and input, which provide basic input-output functionality for debugging and user interaction. Developers can also register custom classes using the addClass method, which allows JIT code to instantiate and manipulate objects of types defined in the host application, enabling seamless integration between statically compiled C++ code and dynamically compiled JIT code. Once all necessary APIs and classes have been registered, the developer calls the parse method with the source code string, which triggers the lexical analysis and syntax parsing phases that construct an internal abstract syntax tree

representing the program structure.

The final steps in the quick start process involve executing the parsed code or compiling it to machine code for later execution, providing flexibility based on the specific use case requirements. The execute method triggers an interpreter-style execution of the abstract syntax tree, which is useful for rapid prototyping and debugging because it bypasses the machine code generation phase and immediately runs the program using the evaluator functions built into the parser. For production use where maximum performance is required, the compile method triggers machine code generation for the target CPU architecture, producing a buffer of executable instructions that can be saved to disk or executed directly in memory. The getExecutableCode method returns a pointer to the compiled function that can be cast to a function pointer of the appropriate signature and called directly from C++, achieving native performance comparable to ahead-of-time compiled code. This dual-mode execution capability allows developers to iterate quickly during development while still being able to deploy optimized versions when the code is stable and performance requirements are stringent.

## Class Interface

The JITCompiler class serves as the primary interface for machine code generation and

optimization, providing methods for CPU feature detection, code emission, and memory

management across supported architectures. This class internally maintains an instance of a CPUInfo object that detects available CPU features at runtime using cpuid instructions on X86-64 or reading /proc/cpuinfo on ARM64 and RISC-V systems, enabling the code generator to select optimal instruction sequences based on the host processor's capabilities. The class provides beginFunction and endFunction methods that delineate the start and end of a compiled function, automatically generating prologue and epilogue code that manages stack frames and preserves callee-saved registers according to the platform's calling convention. Developers can add

individual machine instructions using methods like emitMovImm, emitAdd, and emitCall, but more commonly they use the higher-level statement and expression interfaces that automatically generate sequences of instructions for complex operations like loops, conditionals, and function calls. The optimization level can be adjusted at any time using the setOptimizationLevel method, which reconfigures the internal optimizer to apply different transformations ranging from basic constant folding at O0 to aggressive loop unrolling and function inlining at O3.

The MultiLanguageJIT class wraps the JITCompiler and provides the high-level interface for parsing and executing source code, acting as the bridge between the lexer, parser, and code generator components. This class maintains a registry of global variables, classes, and API functions that are accessible from within the JIT code, providing a rich runtime environment for executing dynamically compiled programs. The parse method takes a string of source code and processes it through a three-phase pipeline: lexical analysis where the MultiLanguageLexer breaks the source into tokens, syntax analysis where the Parser constructs an abstract syntax tree from the token stream, and semantic analysis where the system checks for type errors and resolves symbol references. The lexer employs a lookahead mechanism that can peek up to three characters ahead to correctly identify multi-character operators like ">>=" and "..." while

distinguishing them from sequences of single-character operators, ensuring accurate tokenization across all supported languages. The parser uses a recursive descent algorithm with operator precedence climbing for expression parsing, which provides a natural mapping between grammar rules and parsing functions while maintaining the ability to handle complex expressions with nested parentheses and multiple operator types.

The Box class serves as the universal container for all data values that flow through the JIT system, providing a type-safe union that can hold primitive types, strings, containers, functions, and object instances while supporting arithmetic, bitwise, and comparison operations through overloaded operators. Each Box object stores a type tag that identifies the kind of data currently stored, along with a union of possible value representations that share the same memory space to minimize memory overhead while maximizing performance. The class provides conversion methods such as toInt64, toDouble, and toString that perform type coercion when possible or return default values when conversion is not defined, ensuring that operations never fail due to type mismatches but instead produce predictable results. The Box class also implements container methods including push_back, size, and operator[] for vector and list access, as well as insert and find methods for map and set operations, providing a consistent interface for all collection types regardless of their underlying implementation. For object instances, the Box stores a shared pointer to an ObjectInstance that contains the actual instance data, property values, and a pointer to the class's vtable, enabling polymorphic behavior through the callMethod method.

## Manual

The manual for the Multi-Language JIT Compiler System provides comprehensive guidance on using all features and APIs, organized into sections covering language syntax, API reference, compilation options, and troubleshooting techniques. Users should begin by understanding the core execution model, where source code is first parsed into an abstract syntax tree that can be either interpreted immediately or compiled to machine code for later execution, with the interpreter being useful for development and the compiler for production deployment. The source code syntax varies by language, but the system supports common constructs across all languages including variable declarations using var or let keywords, assignment statements with = or := operators, conditional execution with if-else blocks, iteration with while, for, and for-each loops, and function definitions with def, func, or function keywords. The system automatically handles language-specific quirks such as semicolon insertion in JavaScript, significant whitespace in Python, and explicit block terminators in BASIC and COBOL, providing a consistent execution environment regardless of the source language's original design.

When working with classes and objects, developers should understand the vtable mechanism that enables virtual method dispatch, where each class instance stores a pointer to a table of function addresses that is shared among all instances of the same class. This vtable is automatically generated by the compiler when it encounters virtual method declarations, with the table layout following the inheritance hierarchy where base class virtual functions appear first followed by derived class additions. Memory layout for class instances includes the vtable pointer at offset zero followed by property values in the order they were declared, with padding inserted as needed to maintain alignment requirements of the target architecture. Inheritance affects memory layout by placing base class subobjects before derived class properties, with multiple inheritance requiring additional adjustments to ensure proper offset calculations when casting between base and derived types. The system supports both single and multiple inheritance, though virtual inheritance is not currently implemented due to its complexity and relatively rare usage in performance-critical JIT-compiled code.

The optimization system provides multiple levels of code transformation that progressively improve performance at the cost of increased compilation time, with O0 producing debuggable code with no optimizations, O1 performing basic constant folding and dead code elimination, O2 adding loop optimizations and vectorization, and O3 including aggressive inlining and advanced alias analysis. Constant folding evaluates expressions at compile time when all operands are constants,

replacing "2 + 2" with "4" and eliminating unnecessary runtime computations, while strength reduction replaces expensive operations with cheaper equivalents such as converting

multiplication by 2 to a left shift operation. Constant propagation tracks variable values through the program to replace variable references with known constants, enabling further constant folding and dead code elimination, while common subexpression elimination identifies repeated

calculations and computes them once with the result reused across multiple uses. Loop

optimizations include loop invariant code motion that moves computations that don't change during loop execution outside the loop body, loop unrolling that replicates loop bodies to reduce branch overhead, and vectorization that transforms scalar operations into SIMD instructions when the target CPU supports them.

## Sample Two: Factorial Calculation with Loop Constructs

The second sample implements the classic factorial calculation using while loops, demonstrating the system's ability to execute iterative algorithms with conditional branching and variable updates across multiple iterations. The program begins by declaring three variables: n initialized to 5

representing the input value whose factorial will be calculated, result initialized to 1 which will accumulate the product as the loop executes, and i initialized to 1 which serves as the loop counter that increments from 1 up to n. The while loop condition checks whether i is less than or equal to n before each iteration, and as long as this condition evaluates to true, the loop body executes the factorial multiplication by updating the result variable to be result multiplied by i, effectively computing the running product of all integers from 1 to n. After the multiplication, the loop increments i by 1 using the addition assignment operator, ensuring that the loop counter advances and eventually causes the loop condition to become false when i exceeds n, terminating the iteration. Each iteration includes a println call that outputs the current values of i and result, providing visibility into the loop's progression and allowing developers to verify that the calculation is proceeding correctly at each step.

The factorial algorithm's complexity is O(n) linear time, meaning that the number of operations grows proportionally to the input value, which for n=5 results in five iterations producing the correct result of 120 (1 * 2 * 3 * 4 * 5 = 120). The while loop construct demonstrates the system's ability to handle both pre-test loops where the condition is evaluated before the first iteration, ensuring that the loop body may execute zero times if the condition is initially false, and the loop variable updates that occur within the body guarantee eventual termination when the variable approaches the boundary condition. The variable scoping rules in the JIT system follow the block-level semantics common to C-family languages, where variables declared within a block are only accessible within that block and its nested blocks, while variables declared at the outer level remain accessible throughout the function. The sample's output shows each iteration's state, culminating in the final factorial value being displayed after the loop completes, demonstrating that the JIT's evaluation of loop conditions and variable updates correctly implements the expected semantics of iterative computation.

```text
        }
```

```text
        return nullptr;

        auto it = name_to_index.find(name);

    size_t instance_size;
    size_t property_offset_counter;
public:
    ClassDecl(const std::string& n)
        : name(n), instance_size(0), property_offset_counter(sizeof(void*)) {
        vtable = std::make_shared<VTable>();
    }

    void addBaseClass(std::shared_ptr<ClassDecl> base) {
        base_classes.push_back(base);

        for (auto& [prop_name, prop] : base->getProperties()) {
            if (prop->visibility != Visibility::PRIVATE) {
                prop->offset = property_offset_counter;
                property_offset_counter += sizeof(Box);
                properties[prop_name] = prop;
            }
        }

        for (auto& entry : base->vtable->getEntries()) {
            if (entry.is_virtual) {
                auto existing = methods.find(entry.method_name);
                if (existing == methods.end()) {
                    vtable->addEntry(entry.method_name, true);
                }
            }
        }

        instance_size = property_offset_counter;
    }

    void addProperty(std::shared_ptr<PropertyDecl> prop) {
        prop->offset = property_offset_counter;
        property_offset_counter += sizeof(Box);
        properties[prop->name] = prop;
        instance_size = property_offset_counter;
    }

    void addMethod(std::shared_ptr<MethodDecl> method) {
        if (method->is_virtual) {
            size_t existing_index = vtable->size();
            for (size_t i = 0; i < vtable->size(); i++) {
                if (vtable->getEntries()[i].method_name == method->name) {
                    existing_index = i;
                    break;
                }
            }

            if (existing_index < vtable->size()) {
                method->vtable_index = existing_index;
                method->is_override = true;
            } else {
                vtable->addEntry(method->name, true);
                method->vtable_index = vtable->size() - 1;
            }
        }
        methods[method->name] = method;
    }

    void setConstructor(std::shared_ptr<MethodDecl> ctor) { constructor = ctor; }
    void setDestructor(std::shared_ptr<MethodDecl> dtor) { destructor = dtor; }

    void setStaticMember(const std::string& name, const Box& value) { static_members[name] = value; }

    Box getStaticMember(const std::string& name) const {
        auto it = static_members.find(name);
        if (it != static_members.end()) return it->second;
        return Box();
    }

    std::shared_ptr<PropertyDecl> getProperty(const std::string& name) const {
        auto it = properties.find(name);
        if (it != properties.end()) return it->second;
        for (auto& base : base_classes) {
            auto prop = base->getProperty(name);
            if (prop) return prop;
        }
        return nullptr;
    }

    std::shared_ptr<MethodDecl> getMethod(const std::string& name) const {
        auto it = methods.find(name);
        if (it != methods.end()) return it->second;
        for (auto& base : base_classes) {
            auto method = base->getMethod(name);
            if (method) return method;
        }
        return nullptr;
    }

    const auto& getProperties() const { return properties; }
    const auto& getMethods() const { return methods; }
    std::string getName() const { return name; }
    auto getConstructor() const { return constructor; }
    auto getDestructor() const { return destructor; }
    auto getVTable() const { return vtable; }
    size_t getInstanceSize() const { return instance_size; }
};
```

```text
        if (prop) {
            Box* prop_ptr = reinterpret_cast<Box*>(instance_data.data() + prop->offset);
            *prop_ptr = value;
        }
    }

    Box getProperty(const std::string& name) const {
        auto prop = class_def->getProperty(name);
        if (prop) {

            Box* prop_ptr = reinterpret_cast<Box*>(const_cast<uint8_t*>(instance_data.data()) + prop->offset);
            return *prop_ptr;
        }
        return Box();
    }

        auto method = class_def->getMethod(name);
        if (method) {
            if (method->is_virtual && vtable_ptr) {
                void* func = vtable_ptr->getFunctionPtr(name);

                    typedef Box (*VirtualMethod)(ObjectInstance*, std::vector<Box>&);
                    VirtualMethod vm = reinterpret_cast<VirtualMethod>(func);
                    return vm(this, args);
                }
            }
            return method->call(args);
        }
        return Box();
    }

    void* getInstanceData() { return instance_data.data(); }
};
```

```text
class MultiLanguageLexer {
private:
    std::string source;
    size_t pos;
    int line;
    int column;
    Language current_lang;

    char peek() const { return pos < source.length() ? source[pos] : '\0'; }
    char peekNext() const { return pos + 1 < source.length() ? source[pos + 1] : '\0'; }
    char peekNext2() const { return pos + 2 < source.length() ? source[pos + 2] : '\0'; }

    char advance() {
        char c = peek();
        if (c == '\n') { line++; column = 1; }
        else if (c != '\0') column++;
        if (pos < source.length()) pos++;
        return c;
    }

    void skipWhitespace() {
        while (isspace(peek())) advance();
    }

    bool isIdentifierStart(char c) { return isalpha(c) || c == '_' || c == '@' || c == '$'; }
    bool isIdentifierChar(char c) { return isalnum(c) || c == '_' || c == '@' || c == '$'; }
    bool isDigit(char c) { return isdigit(c); }

    Token readNumber() {
        std::string num;
        int start_line = line, start_col = column;
        bool is_float = false;
        bool is_hex = false;
        bool is_binary = false;
        if (peek() == '0' && (peekNext() == 'x' || peekNext() == 'X')) {
            is_hex = true;
            num += advance(); num += advance();
        } else if (peek() == '0' && (peekNext() == 'b' || peekNext() == 'B')) {
            is_binary = true;
            num += advance(); num += advance();
        }

        while (peek() != '\0') {
            if (isDigit(peek())) {
                num += advance();
            } else if (!is_hex && !is_binary && peek() == '.') {
                is_float = true;
                num += advance();
            } else if (is_hex && (isxdigit(peek()))) {
                num += advance();
            } else if (is_binary && (peek() == '0' || peek() == '1')) {
                num += advance();
            } else if (!is_hex && !is_binary && (peek() == 'e' || peek() == 'E')) {
                is_float = true;
                num += advance();
                if (peek() == '+' || peek() == '-') num += advance();
            } else {
                break;
            }
        }

        Box value;
        if (is_hex) {
            value = Box((int64_t)std::stoll(num, nullptr, 16));
        } else if (is_binary) {
            value = Box((int64_t)std::stoll(num.substr(2), nullptr, 2));
        } else if (is_float) {
            value = Box(std::stod(num));
        } else {
            value = Box((int64_t)std::stoll(num));
        }

        return Token(TokenType::NUMBER, num, start_line, start_col);
    }

    Token readString(char quote) {
        std::string str;
        int start_line = line, start_col = column;
        advance();

        while (peek() != quote && peek() != '\0') {
            if (peek() == '\\') {
                advance();
                switch (peek()) {
                    case 'n': str += '\n'; break;
                    case 't': str += '\t'; break;
                    case 'r': str += '\r'; break;
                    case '0': str += '\0'; break;
                    case '\\': str += '\\'; break;
                    case '\'': str += '\''; break;
                    case '"': str += '"'; break;
                    default: str += peek(); break;
                }
                advance();
            } else {
                str += advance();
            }
        }
        if (peek() == quote) advance();
        return Token(TokenType::STRING, str, start_line, start_col);
    }

    Token readIdentifier() {
        std::string ident;
        int start_line = line, start_col = column;

        while (isIdentifierChar(peek())) ident += advance();

        static const std::unordered_map<std::string, TokenType> keywords = {
            // Control flow
            {"if", TokenType::KW_IF}, {"else", TokenType::KW_ELSE},
            {"while", TokenType::KW_WHILE}, {"for", TokenType::KW_FOR},
            {"return", TokenType::KW_RETURN}, {"break", TokenType::KW_BREAK},
            {"continue", TokenType::KW_CONTINUE}, {"goto", TokenType::KW_GOTO},
            {"switch", TokenType::KW_SWITCH}, {"case", TokenType::KW_CASE},
            {"default", TokenType::KW_DEFAULT},

            // Classes and objects
            {"class", TokenType::KW_CLASS}, {"struct", TokenType::KW_STRUCT},
            {"new", TokenType::KW_NEW}, {"delete", TokenType::KW_DELETE},
            {"this", TokenType::KW_THIS}, {"super", TokenType::KW_SUPER},
            {"extends", TokenType::KW_EXTENDS}, {"implements", TokenType::KW_IMPLEMENTS},

            // Values
            {"true", TokenType::KW_TRUE}, {"false", TokenType::KW_FALSE},
            {"null", TokenType::KW_VOID}, {"NULL", TokenType::KW_VOID},

            // Types
            {"int", TokenType::KW_INT}, {"int8", TokenType::KW_INT8},
            {"int16", TokenType::KW_INT16}, {"int32", TokenType::KW_INT32},
            {"int64", TokenType::KW_INT64}, {"uint", TokenType::KW_UINT},
            {"uint8", TokenType::KW_UINT8}, {"uint16", TokenType::KW_UINT16},
            {"uint32", TokenType::KW_UINT32}, {"uint64", TokenType::KW_UINT64},
            {"float", TokenType::KW_FLOAT}, {"double", TokenType::KW_DOUBLE},
            {"bool", TokenType::KW_BOOL}, {"char", TokenType::KW_CHAR},
            {"string", TokenType::KW_STRING}, {"void", TokenType::KW_VOID},
            {"auto", TokenType::KW_AUTO}, {"static", TokenType::KW_STATIC},
            {"extern", TokenType::KW_EXTERN}, {"const", TokenType::KW_CONST},

            // Variables
            {"var", TokenType::KW_VAR}, {"let", TokenType::KW_LET},

            // Functions
            {"def", TokenType::KW_DEF}, {"func", TokenType::KW_FUNC},
            {"function", TokenType::KW_FUNCTION}, {"procedure", TokenType::KW_PROCEDURE},

            // I/O
            {"print", TokenType::KW_PRINT}, {"println", TokenType::KW_PRINT},
            {"input", TokenType::KW_INPUT}, {"read", TokenType::KW_READ},
            {"write", TokenType::KW_WRITE},

            // OOP modifiers
            {"virtual", TokenType::KW_VIRTUAL}, {"override", TokenType::KW_OVERRIDE},
            {"final", TokenType::KW_FINAL}, {"abstract", TokenType::KW_ABSTRACT},
            {"public", TokenType::KW_PUBLIC}, {"private", TokenType::KW_PRIVATE},
            {"protected", TokenType::KW_PROTECTED}, {"static", TokenType::KW_STATIC},

            // Exception handling
            {"try", TokenType::KW_TRY}, {"catch", TokenType::KW_CATCH},
            {"throw", TokenType::KW_THROW}, {"finally", TokenType::KW_FINALLY},

            // Bitwise type keywords (for explicit bit operations)
            {"bitand", TokenType::AMP}, {"bitor", TokenType::PIPE},
            {"xor", TokenType::CARET}, {"compl", TokenType::TILDE},
            {"and_eq", TokenType::AMP_ASSIGN}, {"or_eq", TokenType::PIPE_ASSIGN},
            {"xor_eq", TokenType::CARET_ASSIGN}
        };

        auto it = keywords.find(ident);
        if (it != keywords.end()) {
            return Token(it->second, ident, start_line, start_col);
        }

        return Token(TokenType::IDENTIFIER, ident, start_line, start_col);
    }

    Token readOperator() {
        int start_line = line, start_col = column;
        char c = peek();

        // Multi-character operators (priority: 3 chars, then 2 chars)

        // 3-character operators
        if (c == '.' && peekNext() == '.' && peekNext2() == '.') {
            advance(); advance(); advance();
            return Token(TokenType::DOT_DOT_DOT, "...", start_line, start_col);
        }

        // 2-character operators
        if (c == '+' && peekNext() == '+') { advance(); advance(); return
Token(TokenType::PLUS_PLUS, "++", start_line, start_col); }
        if (c == '-' && peekNext() == '-') { advance(); advance(); return
Token(TokenType::MINUS_MINUS, "--", start_line, start_col); }

        if (c == '=' && peekNext() == '=') { advance(); advance(); return Token(TokenType::EQ, "==", start_line, start_col); }

        if (c == '!' && peekNext() == '=') { advance(); advance(); return Token(TokenType::NE, "!=", start_line, start_col); }
        if (c == '<' && peekNext() == '=') { advance(); advance(); return Token(TokenType::LE, "<=", start_line, start_col); }

        if (c == '>' && peekNext() == '=') { advance(); advance(); return Token(TokenType::GE, ">=", start_line, start_col); }

        // Logical operators
        if (c == '&' && peekNext() == '&') { advance(); advance(); return
Token(TokenType::LOGICAL_AND, "&&", start_line, start_col); }
        if (c == '|' && peekNext() == '|') { advance(); advance(); return
Token(TokenType::LOGICAL_OR, "||", start_line, start_col); }

        // Bitwise shift operators
        if (c == '<' && peekNext() == '<') {
            advance(); advance();

            if (peek() == '=') { advance(); return Token(TokenType::SHL_ASSIGN, "<<=", start_line, start_col); }
            return Token(TokenType::SHL, "<<", start_line, start_col);
        }
        if (c == '>' && peekNext() == '>') {
            advance(); advance();

            if (peek() == '=') { advance(); return Token(TokenType::SHR_ASSIGN, ">>=", start_line, start_col); }
            return Token(TokenType::SHR, ">>", start_line, start_col);
        }

        // Compound assignment operators
        if (c == '+' && peekNext() == '=') { advance(); advance(); return
Token(TokenType::PLUS_ASSIGN, "+=", start_line, start_col); }
        if (c == '-' && peekNext() == '=') { advance(); advance(); return
Token(TokenType::MINUS_ASSIGN, "-=", start_line, start_col); }
        if (c == '*' && peekNext() == '=') { advance(); advance(); return
Token(TokenType::STAR_ASSIGN, "*=", start_line, start_col); }
        if (c == '/' && peekNext() == '=') { advance(); advance(); return
Token(TokenType::SLASH_ASSIGN, "/=", start_line, start_col); }
        if (c == '%' && peekNext() == '=') { advance(); advance(); return
Token(TokenType::PERCENT_ASSIGN, "%=", start_line, start_col); }
        // Bitwise compound assignment operators
        if (c == '&' && peekNext() == '=') { advance(); advance(); return
Token(TokenType::AMP_ASSIGN, "&=", start_line, start_col); }
        if (c == '|' && peekNext() == '=') { advance(); advance(); return
Token(TokenType::PIPE_ASSIGN, "|=", start_line, start_col); }
        if (c == '^' && peekNext() == '=') { advance(); advance(); return
Token(TokenType::CARET_ASSIGN, "^=", start_line, start_col); }

        // Single-character operators
        advance();
        switch(c) {
            // Arithmetic
            case '+': return Token(TokenType::PLUS, "+", start_line, start_col);
            case '-': return Token(TokenType::MINUS, "-", start_line, start_col);
            case '*': return Token(TokenType::STAR, "*", start_line, start_col);
            case '/': return Token(TokenType::SLASH, "/", start_line, start_col);
            case '%': return Token(TokenType::PERCENT, "%", start_line, start_col);

            // Bitwise
            case '&': return Token(TokenType::AMP, "&", start_line, start_col);
            case '|': return Token(TokenType::PIPE, "|", start_line, start_col);
            case '^': return Token(TokenType::CARET, "^", start_line, start_col);
            case '~': return Token(TokenType::TILDE, "~", start_line, start_col);

            // Assignment and comparison
            case '=': return Token(TokenType::ASSIGN, "=", start_line, start_col);
            case '<': return Token(TokenType::LT, "<", start_line, start_col);
            case '>': return Token(TokenType::GT, ">", start_line, start_col);
            case '!': return Token(TokenType::LOGICAL_NOT, "!", start_line, start_col);

            // Delimiters
            '(': return Token(TokenType::LPAREN, "(", start_line, start_col);
            ')': return Token(TokenType::RPAREN, ")", start_line, start_col);
            '{': return Token(TokenType::LBRACE, "{", start_line, start_col);
            '}': return Token(TokenType::RBRACE, "}", start_line, start_col);
            '[': return Token(TokenType::LBRACK, "[", start_line, start_col);
            ']': return Token(TokenType::RBRACK, "]", start_line, start_col);
            ';': return Token(TokenType::SEMICOLON, ";", start_line, start_col);
            ':': return Token(TokenType::COLON, ":", start_line, start_col);
            ',': return Token(TokenType::COMMA, ",", start_line, start_col);
            '.': return Token(TokenType::DOT, ".", start_line, start_col);

            default: return Token(TokenType::ERROR, std::string(1, c), start_line, start_col);
        }
    }

    Token readComment() {
        int start_line = line, start_col = column;
        std::string comment;

        if (peek() == '/' && peekNext() == '/') {
            advance(); advance();
            while (peek() != '\n' && peek() != '\0') comment += advance();
        } else if (peek() == '/' && peekNext() == '*') {
            advance(); advance();
            while (!(peek() == '*' && peekNext() == '/') && peek() != '\0') {
                if (peek() == '\n') line++;
                comment += advance();
            }
            if (peek() == '*') advance();
            if (peek() == '/') advance();
        } else if (peek() == '#') {
            advance();
            while (peek() != '\n' && peek() != '\0') comment += advance();
        }
        return Token(TokenType::COMMENT, comment, start_line, start_col);
    }

public:
    MultiLanguageLexer(const std::string& src, Language lang = Language::UNKNOWN)
        : source(src), pos(0), line(1), column(1), current_lang(lang) {}

    Token readNext() {
        skipWhitespace();

        if (pos >= source.length()) {
            return Token(TokenType::EOF_TOKEN, "", line, column);
        }

        char c = peek();

        if (isDigit(c) || (c == '.' && isDigit(peekNext()))) {
            return readNumber();
        }

        if (c == '"' || c == '\'') {
            return readString(c);
        }

        if ((c == '/' && (peekNext() == '/' || peekNext() == '*')) || c == '#') {
            return readComment();
        }

        if (isIdentifierStart(c)) {
            return readIdentifier();
        }

        return readOperator();
    }

    std::vector<Token> tokenize() {
        std::vector<Token> tokens;
        Token tok = readNext();
        while (tok.type != TokenType::EOF_TOKEN) {
            tokens.push_back(tok);
            tok = readNext();
        }
        return tokens;
    }

    void setLanguage(Language lang) { current_lang = lang; }
};
```

```text
class LanguageDetector {
private:
    std::string source;

    Language detectByShebang() {
        if (source.length() >= 2 && source[0] == '#' && source[1] == '!') {
            if (source.find("python") != std::string::npos) return Language::PYTHON;
            if (source.find("go") != std::string::npos) return Language::GO;
            if (source.find("node") != std::string::npos) return Language::JAVASCRIPT;
        }
        return Language::UNKNOWN;
    }
    Language detectByKeywords() {
        std::vector<std::pair<Language, std::vector<std::string>>> patterns = {

            {Language::CPP, {"class", "public:", "private:", "virtual", "template", "std::", "->", "&", "|", "^", "~", "<<", ">>"}},
            {Language::C, {"#include", "printf", "scanf", "malloc", "free", "int main"}},
            {Language::PYTHON, {"def ", "import ", "from ", "print(", "class ", "self", "if __name__"}},
            {Language::GO, {"package ", "func ", "go ", "defer ", "chan ", "make("}},
            {Language::BASIC, {"PRINT ", "INPUT ", "LET ", "DIM ", "GOTO ", "END "}},

            {Language::COBOL, {"IDENTIFICATION DIVISION", "DATA DIVISION", "PROCEDURE DIVISION"}},
            {Language::JAVASCRIPT, {"function", "console.log", "let ", "const ", "=>", "document"}}
        };

        int scores[7] = {0};

        for (size_t i = 0; i < patterns.size(); i++) {
            for (const auto& pattern : patterns[i].second) {
                if (source.find(pattern) != std::string::npos) {
                    scores[i]++;
                }
            }
        }

        int max_score = 0;
        Language detected = Language::UNKNOWN;
        for (int i = 0; i < 7; i++) {
            if (scores[i] > max_score) {
                max_score = scores[i];
                detected = static_cast<Language>(i);
            }
        }
        return max_score > 0 ? detected : Language::UNKNOWN;
    }

public:
    LanguageDetector(const std::string& src) : source(src) {}

    Language detect() {
        Language lang = detectByShebang();
        if (lang != Language::UNKNOWN) return lang;

        lang = detectByKeywords();
        if (lang != Language::UNKNOWN) return lang;

        if (source.find('{') != std::string::npos && source.find(';') != std::string::npos) {
            if (source.find("class") != std::string::npos || source.find("namespace") != std::string::npos) {
                return Language::CPP;
            }
            return Language::C;
        }

        if (source.find(":") != std::string::npos && source.find("def ") != std::string::npos) {
            return Language::PYTHON;
        }

        return Language::CPP;
    }
};
```

```text
class Parser {
private:
    std::vector<Token> tokens;
    size_t pos;
    Language current_lang;
    std::shared_ptr<Block> current_block;

    Token& current() { return tokens[pos]; }
    Token& peek(int offset = 0) { return tokens[pos + offset]; }
    void advance() { pos++; }
    bool isAtEnd() { return pos >= tokens.size() || current().type == TokenType::EOF_TOKEN; }

    bool match(TokenType type) {
        if (!isAtEnd() && current().type == type) {
            advance();
            return true;
        }
        return false;
    }

    Token consume(TokenType type, const std::string& error_msg) {
        if (match(type)) return tokens[pos - 1];
        throw std::runtime_error(error_msg + " at line " + std::to_string(current().line));
    }

    // Expression parsing with precedence (including bitwise operators)
    std::shared_ptr<Expr> parseExpression(int precedence = 0) {
        std::shared_ptr<Expr> left = parsePrimary();

        while (!isAtEnd()) {
            BinOp op;
            int new_precedence = 0;
            switch(current().type) {
                // Arithmetic (highest precedence)
                case TokenType::STAR: op = BinOp::MUL; new_precedence = 20; break;
                case TokenType::SLASH: op = BinOp::DIV; new_precedence = 20; break;
                case TokenType::PERCENT: op = BinOp::MOD; new_precedence = 20; break;
                case TokenType::PLUS: op = BinOp::ADD; new_precedence = 10; break;
                case TokenType::MINUS: op = BinOp::SUB; new_precedence = 10; break;

                // Bitwise shift
                case TokenType::SHL: op = BinOp::SHL; new_precedence = 9; break;
                case TokenType::SHR: op = BinOp::SHR; new_precedence = 9; break;

                // Comparison
                case TokenType::LT: op = BinOp::LT; new_precedence = 8; break;
                case TokenType::GT: op = BinOp::GT; new_precedence = 8; break;
                case TokenType::LE: op = BinOp::LE; new_precedence = 8; break;
                case TokenType::GE: op = BinOp::GE; new_precedence = 8; break;

                // Equality
                case TokenType::EQ: op = BinOp::EQ; new_precedence = 7; break;
                case TokenType::NE: op = BinOp::NE; new_precedence = 7; break;

                // Bitwise AND
                case TokenType::AMP: op = BinOp::BIT_AND; new_precedence = 6; break;

                // Bitwise XOR
                case TokenType::CARET: op = BinOp::BIT_XOR; new_precedence = 5; break;

                // Bitwise OR
                case TokenType::PIPE: op = BinOp::BIT_OR; new_precedence = 4; break;

                // Logical AND
                case TokenType::LOGICAL_AND: op = BinOp::LOG_AND; new_precedence = 3; break;

                // Logical OR (lowest precedence)
                case TokenType::LOGICAL_OR: op = BinOp::LOG_OR; new_precedence = 2; break;

                default: return left;
            }

            if (new_precedence < precedence) return left;

            advance();
            std::shared_ptr<Expr> right = parseExpression(new_precedence + 1);
            left = Expr::BinOp(op, left, right);
        }

        return left;
    }

    std::shared_ptr<Expr> parsePrimary() {
        // Unary operators
        if (match(TokenType::PLUS) || match(TokenType::MINUS) ||
            match(TokenType::LOGICAL_NOT) || match(TokenType::TILDE)) {
            TokenType op_type = tokens[pos - 1].type;
            std::shared_ptr<Expr> operand = parsePrimary();

            if (op_type == TokenType::MINUS) {
                return Expr::UnaryOp(UnaryOp::NEG, operand);
            } else if (op_type == TokenType::LOGICAL_NOT) {
                return Expr::UnaryOp(UnaryOp::NOT, operand);
            } else if (op_type == TokenType::TILDE) {
                return Expr::UnaryOp(UnaryOp::BIT_NOT, operand);
            }
            return operand;
        }

        if (match(TokenType::PLUS_PLUS)) {
            // Pre-increment
            Token var = consume(TokenType::IDENTIFIER, "Expected variable");
            return Expr::BinOp(BinOp::ADD, Expr::Var(var.lexeme), Expr::Const(Box(1)));
        }

        if (match(TokenType::MINUS_MINUS)) {
            // Pre-decrement
            Token var = consume(TokenType::IDENTIFIER, "Expected variable");
            return Expr::BinOp(BinOp::SUB, Expr::Var(var.lexeme), Expr::Const(Box(1)));
        }

        if (match(TokenType::NUMBER)) {
            Token tok = tokens[pos - 1];
            return Expr::Const(tok.literal_value);
        }

        if (match(TokenType::STRING)) {
            Token tok = tokens[pos - 1];
            return Expr::Const(tok.literal_value);
        }

        if (match(TokenType::KW_TRUE)) {
            return Expr::Const(Box(true));
        }

        if (match(TokenType::KW_FALSE)) {
            return Expr::Const(Box(false));
        }

        if (match(TokenType::KW_NEW)) {
            return parseNewExpression();
        }

        if (match(TokenType::IDENTIFIER)) {
            Token tok = tokens[pos - 1];

            // Post-increment/decrement
            if (match(TokenType::PLUS_PLUS)) {
                return Expr::BinOp(BinOp::ADD, Expr::Var(tok.lexeme), Expr::Const(Box(1)));
            }
            if (match(TokenType::MINUS_MINUS)) {
                return Expr::BinOp(BinOp::SUB, Expr::Var(tok.lexeme), Expr::Const(Box(1)));
            }

            // Function call
            if (match(TokenType::LPAREN)) {
                std::vector<std::shared_ptr<Expr>> args;
                if (current().type != TokenType::RPAREN) {
                    do {
                        args.push_back(parseExpression());
                    } while (match(TokenType::COMMA));
                }
                consume(TokenType::RPAREN, "Expected ')'");
                return Expr::Call(tok.lexeme, args);
            }

            // Member access
            if (match(TokenType::DOT)) {
                Token member = consume(TokenType::IDENTIFIER, "Expected member name");
                return Expr::Member(Expr::Var(tok.lexeme), member.lexeme);
            }

            return Expr::Var(tok.lexeme);
        }

        if (match(TokenType::LPAREN)) {
            std::shared_ptr<Expr> expr = parseExpression();
            consume(TokenType::RPAREN, "Expected ')'");
            return expr;
        }

        throw std::runtime_error("Unexpected token: " + current().lexeme);
    }

    std::shared_ptr<Expr> parseNewExpression() {
        Token class_token = consume(TokenType::IDENTIFIER, "Expected class name after 'new'");

        std::vector<std::shared_ptr<Expr>> args;
        if (match(TokenType::LPAREN)) {
            if (current().type != TokenType::RPAREN) {
                do {
                    args.push_back(parseExpression());
                } while (match(TokenType::COMMA));
            }
            consume(TokenType::RPAREN, "Expected ')'");
        }

        return Expr::New(class_token.lexeme, args);
    }

    std::shared_ptr<Stmt> parseStatement() {
        if (match(TokenType::KW_IF)) {
            return parseIfStatement();
        }

        if (match(TokenType::KW_WHILE)) {
            return parseWhileStatement();
        }

        if (match(TokenType::KW_FOR)) {
            return parseForStatement();
        }

        if (match(TokenType::KW_RETURN)) {
            std::shared_ptr<Expr> expr = nullptr;
            if (current().type != TokenType::SEMICOLON && current().type !=
TokenType::EOF_TOKEN) {
                expr = parseExpression();
            }
            if (match(TokenType::SEMICOLON)) {}
            return Stmt::Return(expr);
        }

        if (match(TokenType::KW_BREAK)) {
            if (match(TokenType::SEMICOLON)) {}
            return Stmt::Expr(Expr::Const(Box()));
        }

        if (match(TokenType::KW_CONTINUE)) {
            if (match(TokenType::SEMICOLON)) {}
            return Stmt::Expr(Expr::Const(Box()));
        }

        if (match(TokenType::KW_CLASS)) {
            return parseClassDeclaration();
        }

        if (match(TokenType::KW_VAR) || match(TokenType::KW_LET) ||
match(TokenType::KW_AUTO)) {
            return parseVariableDeclaration();
        }

        if (match(TokenType::KW_PRINT)) {
            std::shared_ptr<Expr> expr = parseExpression();
            if (match(TokenType::SEMICOLON)) {}
            return Stmt::Expr(Expr::Call("print", {expr}));
        }

        // Assignment or expression
        if (current().type == TokenType::IDENTIFIER) {
            Token name = current();
            advance();

            // Handle compound assignments
            TokenType assign_type = current().type;
            if (assign_type == TokenType::ASSIGN ||
                assign_type == TokenType::PLUS_ASSIGN ||
                assign_type == TokenType::MINUS_ASSIGN ||
                assign_type == TokenType::STAR_ASSIGN ||
                assign_type == TokenType::SLASH_ASSIGN ||
                assign_type == TokenType::PERCENT_ASSIGN ||
                assign_type == TokenType::AMP_ASSIGN ||
                assign_type == TokenType::PIPE_ASSIGN ||
                assign_type == TokenType::CARET_ASSIGN ||
                assign_type == TokenType::SHL_ASSIGN ||
                assign_type == TokenType::SHR_ASSIGN) {
                advance();
                std::shared_ptr<Expr> value = parseExpression();

                // Handle compound assignment transformation
                if (assign_type != TokenType::ASSIGN) {
                    BinOp op;
                    switch(assign_type) {
                        case TokenType::PLUS_ASSIGN: op = BinOp::ADD; break;
                        case TokenType::MINUS_ASSIGN: op = BinOp::SUB; break;
                        case TokenType::STAR_ASSIGN: op = BinOp::MUL; break;
                        case TokenType::SLASH_ASSIGN: op = BinOp::DIV; break;
                        case TokenType::PERCENT_ASSIGN: op = BinOp::MOD; break;
                        case TokenType::AMP_ASSIGN: op = BinOp::BIT_AND; break;
                        case TokenType::PIPE_ASSIGN: op = BinOp::BIT_OR; break;
                        case TokenType::CARET_ASSIGN: op = BinOp::BIT_XOR; break;
                        case TokenType::SHL_ASSIGN: op = BinOp::SHL; break;
                        case TokenType::SHR_ASSIGN: op = BinOp::SHR; break;
                        default: op = BinOp::ADD; break;
                    }
                    value = Expr::BinOp(op, Expr::Var(name.lexeme), value);
                }

                if (match(TokenType::SEMICOLON)) {}
                return Stmt::Assign(name.lexeme, value);
            }

            // Regular expression (function call or variable)
            if (match(TokenType::LPAREN)) {
                std::vector<std::shared_ptr<Expr>> args;
                if (current().type != TokenType::RPAREN) {
                    do {
                        args.push_back(parseExpression());
                    } while (match(TokenType::COMMA));
                }
                consume(TokenType::RPAREN, "Expected ')'");
                if (match(TokenType::SEMICOLON)) {}
                return Stmt::Expr(Expr::Call(name.lexeme, args));
            }
            // Just a variable reference
            if (match(TokenType::SEMICOLON)) {}
            return Stmt::Expr(Expr::Var(name.lexeme));
        }

        std::shared_ptr<Expr> expr = parseExpression();
        if (match(TokenType::SEMICOLON)) {}
        return Stmt::Expr(expr);
    }

    std::shared_ptr<Stmt> parseVariableDeclaration() {
        Token name = consume(TokenType::IDENTIFIER, "Expected variable name");

        std::shared_ptr<Expr> initializer = nullptr;
        if (match(TokenType::ASSIGN)) {
            initializer = parseExpression();
        }

        if (match(TokenType::SEMICOLON)) {}

        return Stmt::VarDecl(name.lexeme, BoxType::BOX, initializer);
    }

    std::shared_ptr<Stmt> parseIfStatement() {
        std::shared_ptr<Expr> cond;
        if (match(TokenType::LPAREN)) {
            cond = parseExpression();
            consume(TokenType::RPAREN, "Expected ')'");
        } else {
            cond = parseExpression();
        }

        std::shared_ptr<Block> then_block = parseBlock();
        std::shared_ptr<Block> else_block = nullptr;

        if (match(TokenType::KW_ELSE)) {
            else_block = parseBlock();
        }

        return Stmt::If(cond, then_block, else_block);
    }

    std::shared_ptr<Stmt> parseWhileStatement() {
        std::shared_ptr<Expr> cond;
        if (match(TokenType::LPAREN)) {
            cond = parseExpression();
            consume(TokenType::RPAREN, "Expected ')'");
        } else {
            cond = parseExpression();
        }

        std::shared_ptr<Block> body = parseBlock();
        return Stmt::While(cond, body);
    }

    std::shared_ptr<Stmt> parseForStatement() {
        if (match(TokenType::LPAREN)) {
            // Parse initialization
            std::shared_ptr<Stmt> init = nullptr;
            if (current().type != TokenType::SEMICOLON) {
                init = parseStatement();
            }
            consume(TokenType::SEMICOLON, "Expected ';'");

            // Parse condition
            std::shared_ptr<Expr> cond = nullptr;
            if (current().type != TokenType::SEMICOLON) {
                cond = parseExpression();
            }
            consume(TokenType::SEMICOLON, "Expected ';'");

            // Parse increment
            std::shared_ptr<Stmt> inc = nullptr;
            if (current().type != TokenType::RPAREN) {
                inc = parseStatement();
            }
            consume(TokenType::RPAREN, "Expected ')'");

            std::shared_ptr<Block> body = parseBlock();

            // Transform to while loop
            std::shared_ptr<Block> transformed = std::make_shared<Block>();
            if (init) transformed->addStmt(init);

            std::shared_ptr<Expr> while_cond = cond ? cond : Expr::Const(Box(true));
            std::shared_ptr<Block> while_body = std::make_shared<Block>();

            for (auto& stmt : body->statements) {
                while_body->addStmt(stmt);
            }
            if (inc) while_body->addStmt(inc);

            transformed->addStmt(Stmt::While(while_cond, while_body));

            auto result = std::make_shared<Block>();
            for (auto& stmt : transformed->statements) {
                result->addStmt(stmt);
            }
            return Stmt::Expr(Expr::Const(Box()));
        }

        throw std::runtime_error("Invalid for loop syntax");
    }

    std::shared_ptr<Stmt> parseClassDeclaration() {
        Token name = consume(TokenType::IDENTIFIER, "Expected class name");

        auto class_decl = std::make_shared<ClassDecl>(name.lexeme);

        if (match(TokenType::COLON) || match(TokenType::KW_EXTENDS)) {
            do {
                Token base_name = consume(TokenType::IDENTIFIER, "Expected base class name");
            } while (match(TokenType::COMMA));
        }

        consume(TokenType::LBRACE, "Expected '{'");

        while (!isAtEnd() && current().type != TokenType::RBRACE) {
            if (match(TokenType::KW_PUBLIC) || match(TokenType::KW_PRIVATE) ||
match(TokenType::KW_PROTECTED)) {}

            if (match(TokenType::KW_FUNC) || match(TokenType::KW_DEF) ||
match(TokenType::KW_FUNCTION)) {
                Token method_name = consume(TokenType::IDENTIFIER, "Expected method name");
                auto method = std::make_shared<MethodDecl>(method_name.lexeme);

                consume(TokenType::LPAREN, "Expected '('");
                if (current().type != TokenType::RPAREN) {
                    do {

                        Token param_name = consume(TokenType::IDENTIFIER, "Expected parameter name");
                        method->addParameter(param_name.lexeme, BoxType::BOX);
                    } while (match(TokenType::COMMA));
                }
                consume(TokenType::RPAREN, "Expected ')'");

                method->body = parseBlock();
                class_decl->addMethod(method);
            } else {
                Token prop_name = consume(TokenType::IDENTIFIER, "Expected property name");
                auto prop = std::make_shared<PropertyDecl>(prop_name.lexeme);

                if (match(TokenType::ASSIGN)) {
                    prop->default_value = Box();
                }
                class_decl->addProperty(prop);
                match(TokenType::SEMICOLON);
            }
        }

        consume(TokenType::RBRACE, "Expected '}'");

        return Stmt::ClassDecl(name.lexeme, class_decl);
    }

    std::shared_ptr<Block> parseBlock() {
        auto block = std::make_shared<Block>();
        block->parent = current_block;

        auto old_block = current_block;
        current_block = block;

        if (match(TokenType::LBRACE)) {
            while (!isAtEnd() && current().type != TokenType::RBRACE) {
                std::shared_ptr<Stmt> stmt = parseStatement();
                block->addStmt(stmt);
            }
            consume(TokenType::RBRACE, "Expected '}'");
        } else {
            std::shared_ptr<Stmt> stmt = parseStatement();
            block->addStmt(stmt);
        }

        current_block = old_block;
        return block;
    }

public:
    Parser(const std::vector<Token>& tok, Language lang)
        : tokens(tok), pos(0), current_lang(lang), current_block(std::make_shared<Block>()) {}

    std::shared_ptr<Block> parse() {
        while (!isAtEnd() && current().type != TokenType::EOF_TOKEN) {
            std::shared_ptr<Stmt> stmt = parseStatement();
            current_block->addStmt(stmt);
        }
        return current_block;
    }
};
```

```text
class MultiLanguageJIT {
private:
    JITCompiler& jit;
    std::shared_ptr<Block> ast;
    std::unordered_map<std::string, Box> globals;
    std::unordered_map<std::string, std::shared_ptr<ClassDecl>> classes;
    std::unordered_map<std::string, std::function<Box(std::vector<Box>&)>> apis;
    Language current_lang;

    Box evaluateExpr(std::shared_ptr<Expr> expr) {
        switch(expr->kind) {
            case Expr::Kind::CONST:
                return expr->const_val;

            case Expr::Kind::VAR: {
                auto it = globals.find(expr->var_name);
                if (it != globals.end()) return it->second;
                return Box();
            }

            case Expr::Kind::BINOP: {
                Box lhs = evaluateExpr(expr->binop.lhs);
                Box rhs = evaluateExpr(expr->binop.rhs);
                switch(expr->binop.op) {
                    case BinOp::ADD: return lhs + rhs;
                    case BinOp::SUB: return lhs - rhs;
                    case BinOp::MUL: return lhs * rhs;
                    case BinOp::DIV: return lhs / rhs;
                    case BinOp::MOD: return lhs % rhs;
                    case BinOp::BIT_AND: return lhs & rhs;
                    case BinOp::BIT_OR: return lhs | rhs;
                    case BinOp::BIT_XOR: return lhs ^ rhs;
                    case BinOp::SHL: return lhs << rhs;
                    case BinOp::SHR: return lhs >> rhs;
                    case BinOp::EQ: return Box(lhs == rhs);
                    case BinOp::NE: return Box(lhs != rhs);
                    case BinOp::LT: return Box(lhs < rhs);
                    case BinOp::LE: return Box(lhs <= rhs);
                    case BinOp::GT: return Box(lhs > rhs);
                    case BinOp::GE: return Box(lhs >= rhs);
                    default: return Box();
                }
            }

            case Expr::Kind::UNARYOP: {
                Box operand = evaluateExpr(expr->unaryop.operand);
                switch(expr->unaryop.op) {
                    case UnaryOp::NEG: return Box(-operand.toDouble());
                    case UnaryOp::NOT: return Box(!operand.toBool());
                    case UnaryOp::BIT_NOT: return Box(~operand.toUInt64());
                    default: return operand;
                }
            }

            case Expr::Kind::CALL: {
                auto it = apis.find(expr->call.name);
                if (it != apis.end()) {
                    std::vector<Box> args;
                    for (auto& arg : expr->call.args) {
                        args.push_back(evaluateExpr(arg));
                    }
                    return it->second(args);
                }
                return Box();
            }

            case Expr::Kind::MEMBER: {
                Box obj = evaluateExpr(expr->member.object);
                if (obj.type == Box::Type::OBJECT && obj.object) {
                    return obj.object->getProperty(expr->member.member);
                }
                return Box();
            }

            case Expr::Kind::NEW: {
                auto it = classes.find(expr->new_expr.class_name);
                if (it != classes.end()) {
                    auto obj = std::make_shared<ObjectInstance>(it->second);
                    return Box(obj);
                }
                return Box();
            }

            default:
                return Box();
        }
    }

    void executeStmt(std::shared_ptr<Stmt> stmt) {
        switch(stmt->kind) {
            case Stmt::Kind::EXPR:
                evaluateExpr(stmt->expr);
                break;

            case Stmt::Kind::ASSIGN:
                globals[stmt->assign.var] = evaluateExpr(stmt->assign.value);
                break;

            case Stmt::Kind::VAR_DECL:
                if (stmt->var_decl.initializer) {
                    globals[stmt->var_decl.var] = evaluateExpr(stmt->var_decl.initializer);
                } else {
                    globals[stmt->var_decl.var] = Box();
                }
                break;

            case Stmt::Kind::CLASS_DECL:
                classes[stmt->class_decl.name] = stmt->class_decl.class_def;
                break;

            case Stmt::Kind::IF: {
                Box cond = evaluateExpr(stmt->if_stmt.cond);
                if (cond.toBool()) {
                    executeBlock(stmt->if_stmt.then_block);
                } else if (stmt->if_stmt.else_block) {
                    executeBlock(stmt->if_stmt.else_block);
                }
                break;
            }

            case Stmt::Kind::WHILE: {
                while (evaluateExpr(stmt->while_stmt.cond).toBool()) {
                    executeBlock(stmt->while_stmt.body);
                }
                break;
            }

            case Stmt::Kind::FOR: {
                for (globals[stmt->for_stmt.var] = evaluateExpr(stmt->for_stmt.start);
                     evaluateExpr(stmt->for_stmt.end).toBool();

                     globals[stmt->for_stmt.var] = globals[stmt->for_stmt.var] + evaluateExpr(stmt->for_stmt.step)) {
                    executeBlock(stmt->for_stmt.body);
                }
                break;
            }

            case Stmt::Kind::RETURN:
                if (stmt->expr) {
                    globals["return_value"] = evaluateExpr(stmt->expr);
                }
                break;

            case Stmt::Kind::BLOCK:
                executeBlock(stmt->block);
                break;

            default:
                break;
        }
    }

    void executeBlock(std::shared_ptr<Block> block) {
        if (!block) return;
        for (auto& stmt : block->statements) {
            executeStmt(stmt);
        }
    }

public:
    MultiLanguageJIT(JITCompiler& compiler) : jit(compiler), current_lang(Language::UNKNOWN) {
        registerBuiltinAPIs();
    }

    void registerBuiltinAPIs() {
        apis["print"] = [](std::vector<Box>& args) -> Box {
            for (auto& arg : args) std::cout << arg.toString();
            return Box();
        };
```
